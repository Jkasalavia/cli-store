Self-hosted app catalog

JKSTORE CLI

A short terminal launcher for the app catalog. Windows users can open the install menu from PowerShell, while Mac users can run the Bash launcher from Terminal.

Windows PowerShell

irm https://jkasalavia.github.io/cli-store/r|iex
Runs the interactive Windows installer menu from the live app-store service.

macOS Terminal

curl -fsSL https://jkasalavia.github.io/cli-store/m|bash
Runs the Mac installer menu using the same app catalog.
